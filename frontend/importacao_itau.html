Como Importar

Faça upload do Extrato para importar recebimentos e do Relatório de Pagamentos para importar despesas. O sistema verificará automaticamente duplicatas e lançamentos previstos.

  • Extrato: Use para importar recebimentos (PIX, cartões, etc.)
  • Relatório de Pagamentos: Use para importar despesas pagas
  • Arquivos devem estar no formato XLSX
